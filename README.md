# Stellarum · Атлас галактики WH40K

Интерактивная карта для GitHub Pages. Откройте `index.html` в браузере или запустите `python -m http.server` из корня проекта. Для Pages выберите ветку `main` и каталог `/ (root)`. Все ресурсы загружаются относительно страницы и входят в репозиторий.

## Навигация

Перетаскивайте карту для вращения. Колесо меняет масштаб. Правая кнопка мыши или Shift с перетаскиванием сдвигает камеру. На сенсорном экране используйте один палец для вращения и два для сдвига и масштабирования. После фокусировки карты доступны стрелки, Shift со стрелками, плюс, минус и Home.

Поиск принимает русские и английские названия. Выбор в каталоге переносит камеру к миру. Нажатие на точку открывает досье. Кнопка с прицелом возвращает общий вид.

## Картография

Каталог содержит 124 мира, включая спутник-кузницу Стигия VIII. Око Ужаса показано отдельным объектом. Описания и ориентиры взяты из пользовательской подборки по опубликованным материалам WH40K. Английские имена облегчают поиск по [Lexicanum](https://wh40k.lexicanum.com/wiki/Planets_(List)). Ориентиры относятся к разным эпохам.

Визуализация использует условные трёхмерные координаты. Крупные ориентиры размещены вручную, другие миры распределены по областям, часть систем сгруппирована. Высота над диском, расстояния и размер аномалии служат для навигации. Объекты без установленного сегментума доступны через фильтр «Без привязки». Фоновая звёздная пыль процедурная.

Данные находятся в `worlds.js`, проекция и управление в `atlas.js`, оформление в `atlas.css`. Независимый фанатский проект по вселенной Warhammer 40,000.
